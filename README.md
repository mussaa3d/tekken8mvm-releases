# tekken8mvm

Installers for tekken8mvm, the Tekken 8 cinematic and movie-making tool.

The tool only runs for supporters: support tekken8mvm on Patreon or Ko-fi with your Discord linked, get the **Early Access** role in the tekken8mvm Discord server, then press **Link Discord** in the tool. It updates itself from here.

tekken8mvm is a fan-made tool. It isn't made or endorsed by Bandai Namco.
